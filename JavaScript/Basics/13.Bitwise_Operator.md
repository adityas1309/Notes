## Introduction

Bitwise operators are a special category of operators in JavaScript that work **directly on binary representations** of numbers.

- Unlike logical operators (e.g., `&&`, `||`), which return Boolean results (`true` or `false`), bitwise operators:
  - Work on **individual bits** of integer values.
  - Perform operations bit-by-bit.
  - Return **numeric results**.

---

## What Are Bitwise Operators?

Bitwise operators manipulate **bits** — the fundamental building blocks of data in memory (`0` and `1`).

### Binary Representation of Numbers

- JavaScript stores numbers internally as binary.
- Example:
  - `5` → `101`
  - `7` → `111`

When using bitwise operators, JavaScript converts numbers into binary, applies bitwise logic, and then converts the result back to decimal.

---

## Types of Bitwise Operators

JavaScript supports several bitwise operators:

### Bitwise AND (`&`)

- Symbol: `&` (single ampersand)
- Compares each bit of two numbers.
- **Returns `1` if both bits are `1`**, otherwise `0`.

### Bitwise OR (`|`)

- Symbol: `|` (single pipe)
- Compares each bit of two numbers.
- **Returns `1` if at least one of the bits is `1`**, otherwise `0`.

### Bitwise XOR (`^`)

- Symbol: `^` (caret)
- Exclusive OR: returns `1` if **only one of the bits is `1`**, not both.

### Bitwise NOT (`~`)

- Symbol: `~` (tilde)
- **Inverts each bit** (flips `1` to `0` and `0` to `1`)
- Applies only to a **single operand**.

## Examples and Demonstrations

### Bitwise AND Examples

1. **5 & 7**

```
5 → 101
7 → 111
------------
    101 → 5
```

→ `5 & 7` = `5`

2. **6 & 9**

```
6 → 0110
9 → 1001
------------
    0000 → 0
```

→ `6 & 9` = `0`

3. **2 & 5**

```
2 → 010
5 → 101
------------
    000 → 0
```

→ `2 & 5` = `0`

4. **15 & 6**

```
15 → 1111
 6 → 0110
------------
    0110 → 6
```

→ `15 & 6` = `6`

5. **5 & 6**

```
5 → 0101
6 → 0110
------------
    0100 → 4
```

→ `5 & 6` = `4`

---

### Bitwise OR Examples

1. **5 | 6**

```
5 → 0101
6 → 0110
------------
    0111 → 7
```

→ `5 | 6` = `7`

2. **8 | 4**

```
8 → 1000
4 → 0100
------------
    1100 → 12
```

→ `8 | 4` = `12`

## How to Convert Binary to Decimal

To convert binary back to decimal:

Each bit represents a power of 2:
```
Binary: 1100
Decimal = 1×2³ + 1×2² + 0×2¹ + 0×2⁰
        = 8 + 4 + 0 + 0
        = 12
```

This is useful when interpreting results of bitwise operations manually.

> 💡 You don’t need to memorize binary values. You can **calculate them step by step** using basic binary math.

## Section Summary

- Bitwise operators apply logic at the **bit level** of numbers.
- **AND (`&`)**: returns 1 only if both bits are 1.
- **OR (`|`)**: returns 1 if at least one bit is 1.
- Operations like `5 & 7` or `6 | 8` are executed by converting to binary, applying bitwise logic, and returning the decimal result.
- XOR (`^`) and NOT (`~`) follow similar principles with distinct behaviors (covered further in advanced lessons).
