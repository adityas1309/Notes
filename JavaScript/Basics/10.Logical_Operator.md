## Introduction to Logical Operators

Logical operators are fundamental tools in JavaScript that allow you to perform **Boolean logic comparisons**. These comparisons return either `true` or `false`.

- They are **commonly used in conditions**, loops, validations, and more.
- You might recall learning about **logic gates** (AND, OR, NOT) in high school electronics or computer science classes.

---

## Boolean Logic Recap

### What Are Logic Gates?

- **Logic gates** are electronic circuits that perform logical operations on **Boolean inputs**.
- Inputs and outputs are either:
  - `true` (current flows)
  - `false` (no current)

These were visualized using standard gate diagrams:

- **AND gate**
- **OR gate**
- **NOT gate**

### True and False as Current Flow

- `true` → Current flows through the circuit
- `false` → No current flows

These concepts translate directly into **logical operations in programming**.

## Types of Logical Operators

### AND Operator (`&&`)

- **Requires two operands**.
- Returns `true` only if **both operands are true**.
- Syntax:
  ```javascript
  true && true   // true
  true && false  // false
  false && true  // false
  false && false // false
  ```

> 🔹 Symbol: `&&` (double ampersand)  
> Located on the keyboard: Shift + 7 or near number keys depending on layout.

---

### OR Operator (`||`)

- **Requires two operands**.
- Returns `true` if **at least one operand is true**.
- Syntax:
  ```javascript
  true || true   // true
  true || false  // true
  false || true  // true
  false || false // false
  ```

> 🔸 Symbol: `||` (double pipe)  
> Usually located **above the Enter key** on your keyboard.

---

### NOT Operator (`!`)

- **Takes only one operand**.
- Reverses the Boolean value:
  - `!true` → `false`
  - `!false` → `true`

> ⚠️ Correction: The NOT operator is **`!`** (exclamation mark), not the tilde (`~`).  
> Tilde is used for **bitwise operations**, which are separate.

---

## JavaScript Syntax and Evaluation

### Basic Logical Expressions

```javascript
console.log(true && false);       // false
console.log(false || false);      // false
console.log(true && true);        // true
```

### Combining with Relational Operators

Relational operators like `<`, `>`, `>=`, `<=` return Boolean values (`true` or `false`), which can be used in logical expressions:

```javascript
console.log(10 > 5 && 6 < 3);      // true && false → false
console.log(5 < 10 || 6 > 9);      // true || false → true
console.log(!false);              // true
console.log(!true);               // false
```

> 🧠 Logical operators often **short-circuit** evaluation:  
> In `true || something`, JavaScript stops after `true` since OR already succeeded.

---

### Important notes on NOT (`!`) Operator

- Use `!` for logical NOT (inversion).
- Example:
  ```javascript
  console.log(!false);  // true
  console.log(!true);   // false
  ```

⚠️ **Avoid confusion**: `~` (tilde) is a **bitwise NOT**, not logical NOT.

---

## Section Summary

- Logical operators (`&&`, `||`, `!`) are used to evaluate multiple conditions.
- **AND (`&&`)** returns true only if **both conditions are true**.
- **OR (`||`)** returns true if **any one condition is true**.
- **NOT (`!`)** inverts the condition — `!true` becomes `false`.
- Logical operators are often used alongside **relational operators** for building conditions.

## Final Overall Summary

This lesson covered the foundational **logical operators** in JavaScript:

### ✅ Key Takeaways:

- Logical operators perform operations on **Boolean values**.
- There are three primary operators:
  - `&&` (AND) — returns true if both operands are true.
  - `||` (OR) — returns true if at least one operand is true.
  - `!` (NOT) — returns the opposite Boolean value.
- They are often used in **decision-making**, **conditions**, and **loop controls**.
- You can combine logical operators with **relational expressions** for more complex logic.

By mastering these, you'll be able to write smarter and more flexible conditional logic in JavaScript.
