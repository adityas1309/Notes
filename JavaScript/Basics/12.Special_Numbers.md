## Introduction

While working with numbers in JavaScript, you encounter more than just standard values like `10`, `-5`, or `3.14`. JavaScript includes **special numeric values** that have unique behaviors and significance in programming:

- `0`
- `-0`
- `NaN` (Not a Number)
- `Infinity`
- `-Infinity`

These numbers may behave differently from what you expect, and understanding them is important for writing robust logic in your code.

---

## Understanding Zero and Negative Zero

In JavaScript, both `0` and `-0` are treated as **numeric values**, but with subtle differences that can be important in certain use cases.

### Why Does JavaScript Have `-0`?

- Most programming languages (like Python or C++) do not distinguish between `0` and `-0`.
- JavaScript does. Both `0` and `-0` exist and are distinct values.

### Use Case in Physics and Game Development

- In game development or simulations, many values represent both **magnitude** and **direction**.
- **Example:** Velocity in a 2D game:
  - If an object is moving and decelerates, it might reach **0 m/s**.
  - If it was moving left, you might want to retain that direction even at 0 velocity.
  - **Using `-0`** tells you the object is facing in the **negative direction**, even though it's stationary.

> 🎮 This is useful for preserving direction in UI animations or simulations when speed = 0.

## Understanding `NaN` (Not a Number)

### What is `NaN`?

- `NaN` stands for **"Not a Number"**, but **it is technically a number** in JavaScript.
- It represents **invalid numeric results** — a way to show that a calculation couldn’t be performed meaningfully.

### When to Use `NaN`

Use `NaN` when:

- You're required to return a number **but no valid number exists**.
- You want to indicate that a computation **failed** or resulted in an **invalid number**.

#### Examples:
```javascript
console.log(10 / 0);          // Infinity
console.log(10 / null);       // Infinity (null becomes 0)
console.log(10 / undefined);  // NaN
console.log(0 / 0);           // NaN
```

- Searching for a string not found in a bucket or array?
  - Return `NaN` instead of -1 or an invalid number.

### Important Property of `NaN`

> ❗ `NaN` is the **only value in JavaScript that is not equal to itself**.

```javascript
console.log(NaN === NaN); // false
```

- This makes `NaN` a **special edge case**.
- Reason: Since it's an "invalid" number, it cannot even be considered equal to another invalid number (even itself).

## Infinity and Negative Infinity

### What is Infinity?

- A numeric representation of a **very large value**.
- Used when calculations **exceed the maximum representable number**, or when you divide by 0.

```javascript
console.log(10 / 0);      // Infinity
console.log(-10 / 0);     // -Infinity
console.log(10 < Infinity);  // true
```

- You can also directly use `Infinity` and `-Infinity` in code.

### Infinity Is a Number

- It’s **not a string** — it's a valid number in JavaScript.
- No quotation marks are used:
  ```javascript
  console.log(typeof Infinity); // 'number'
  ```

## Section Summaries

### Summary: Zero and Negative Zero

- Both `0` and `-0` exist in JavaScript.
- Useful for tracking **directional quantities** when magnitude is zero.
- Helps retain direction in simulations and game logic.

---

### Summary: `NaN`

- Represents an **invalid number** or **failed calculation**.
- Used when:
  - A number is expected, but result isn’t valid.
  - Division by `undefined`, invalid operations, etc.
- **Only value not equal to itself**.

### Summary: Infinity

- `Infinity` and `-Infinity` represent extremely large/small numbers.
- Return value for dividing by zero or very large operations.
- You can compare other numbers to `Infinity`.
