## Why Comments Matter in Programming

- As a software engineer, you’re not writing code just for yourself — you write for:
  - Fellow team members.
  - Future developers maintaining your work.
  - Organizations or open-source communities where collaboration is key.

- Clear and well-documented code is essential:
  - When switching companies or teams, others should understand what you wrote.
  - Comments help maintain long-term readability and clarity.

> 🔑 **Rule of Thumb:** Never write code that only you can understand.

---

## What Are Comments?

### Purpose of Comments

- Comments are textual explanations within code.
- They serve as **documentation** and make code **easier to read and understand**.
- Useful for:
  - Explaining logic.
  - Leaving instructions.
  - Indicating TODOs or assumptions.

### Impact on Code Execution

- JavaScript **ignores comments during execution**.
- Comments do not affect how your program runs or performs.
- They are purely for human readers — **you and your teammates**.

> 🧠 Think of comments as inline **notes** you leave for yourself and others.

---

## Types of Comments in JavaScript

There are **two main types** of comments supported by JavaScript.

---

### Single-Line Comments

- Used for **brief explanations or annotations**.
- Begin with **`//`** (double forward slash).

#### Syntax:
```javascript
// This is a single-line comment
console.log("Hello World"); // Inline comment
```

- The comment continues until the end of the line.
- Visually appears gray or dimmed in most code editors.

---

### Multi-Line Comments

- Used for **longer explanations** spanning multiple lines.
- Start with `/*` and end with `*/`.

#### Syntax:
```javascript
/*
  This is a multi-line comment.
  It can span across multiple lines.
  Useful for documenting functions or blocks of logic.
*/
console.log("End of script");
```

- Everything between `/*` and `*/` is ignored by JavaScript.
- Helps group or block-explain code sections.

---

## Demonstration of Comments

### Sample Code:
```javascript
// This is a greeting message
console.log("Hello World");

/*
  This block explains the following log:
  It prints the final message of the script.
*/
console.log("Ending");
```

### Output:
```
Hello World
Ending
```

> 📝 The comments are **not printed or executed** — they are skipped by JavaScript’s interpreter.

## Section Summary

- Comments are essential tools for writing **maintainable, readable, and collaborative** code.
- JavaScript supports:
  - `//` for **single-line** comments.
  - `/* */` for **multi-line** comments.
- **Best Practice:** Always leave comments when writing complex or non-obvious code.
