## Introduction to Data Types

In JavaScript, **variables can store different types of values** such as numbers, text, or structured data.  
To work effectively with these, it’s important to understand the **types of data** you can store.

- The types of data supported in JavaScript are defined in the official **ECMAScript** documentation.
- This documentation lists the supported language types like:
  - `undefined`
  - `null`
  - `boolean`
  - `string`
  - `symbol`
  - `number`
  - `object`

> 🔹 Fun Fact: JavaScript was historically called **ECMAScript**, and the official documentation still uses that name.

---

## Primitive Data Types

Primitive types are **basic data types** that store simple values. They are **atomic** in nature — they are not built from other types and are **self-contained**.

### 1. Number

- Used to store numeric values, including:
  - Positive/negative integers (`-3`, `0`, `42`)
  - Decimal numbers (`2.6`, `3.14`)
- **Example:**
  ```javascript
  var score = 90;
  var temperature = -2.5;
  ```

### 2. String

- Used to store **textual data**.
- Can be defined using:
  - **Double quotes:** `"Hello"`
  - **Single quotes:** `'World'`
  - **Backticks (template literals):** `` `My name is ${name}` ``
    - Backtick is typically located **below the ESC key** on the keyboard.
- **Example:**
  ```javascript
  var name = "Alice";
  var city = 'Paris';
  var message = `Welcome, ${name}`;
  ```

### 3. Boolean

- Represents **logical values**:
  - `true`
  - `false`
- Commonly used in decision-making or conditions.
- **Example:**
  ```javascript
  var isLoggedIn = true;
  var isGameOver = false;
  ```

> ✅ Boolean values are **keywords** and must be written in lowercase.

### 4. Undefined

- Represents a variable that has been **declared but not assigned** a value yet.
- Can also be used deliberately to denote "not yet defined" state.
- **Example:**
  ```javascript
  var email; // undefined by default
  var status = undefined;
  ```

**Summary of Primitives:**  
These data types are simple and standalone. They include numbers, strings, booleans, and undefined.

## Non-Primitive Data Type

### 5. Object

Objects are **complex structures** used to store **key-value pairs**.

#### Characteristics:
- Keys are **unique** and represent properties.
- Values can be **strings, numbers, booleans**, or even **other objects**.
- Useful to model **real-world entities** like users, products, posts, etc.

#### Syntax Example:
```javascript
var user = {
  name: "Sanket",
  age: 24,
  isActive: true
};
```

#### Nested Object Example:
```javascript
var post = {
  createdAt: "June 12, 2022",
  text: "My first post"
};

var user = {
  name: "Sanket",
  age: 24,
  posts: [post],
  gender: "Male"
};
```

> ✅ Objects allow combining multiple primitive values into a single structured entity.

#### Use Cases:
- Storing user data (name, age, posts, gender)
- Product information (name, cost, color, description)
- Any structure where multiple properties define one meaningful entity

**Summary of Objects:**  
Objects are non-primitive types used to model complex entities by combining multiple values under descriptive keys.

## Primitive vs Non-Primitive

| Feature               | Primitive                           | Non-Primitive (Object)              |
|----------------------|-------------------------------------|-------------------------------------|
| Nature               | Atomic / Self-contained             | Composite / Built from primitives   |
| Examples             | `Number`, `String`, `Boolean`, `Undefined` | `Object`                         |
| Structure            | Holds a single value                | Holds multiple key-value pairs      |
| Use Case             | Basic information                   | Complex data entities               |
| Nesting              | Not applicable                      | Can contain other objects/arrays    |

### Example to Compare:

```javascript
// Primitive
var productName = "iPhone 15";
var price = 130000;
var color = "Deep Purple";

// Non-Primitive
var product = {
  name: "iPhone 15",
  price: 130000,
  color: "Deep Purple",
  discount: 5,
  description: "The new Apple iPhone"
};
```

**Summary:**  
- Primitive types store **basic single values**.
- Non-primitive types like objects store **collections of values**, useful for representing complex real-world data.
