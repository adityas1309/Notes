## Introduction to Special Characters

In programming — including JavaScript and most other languages — there exists a set of **special characters** used within strings to represent things like new lines, tabs, or formatting symbols.

- These are called **escape sequences** or **special characters**.
- They're commonly written using a **backslash (`\`)** followed by a specific character.

> Example of regular characters: `A`, `B`, `1`, `2`, `!`, `?`  
> Example of special characters: `\n`, `\t`, `\\`

---

## Escape Sequences in Strings

Escape sequences are used to represent non-visible characters like new lines or tabs within strings.

### `\n` — New Line

- Inserts a **line break** in the string.
- Acts as if you pressed the **Enter key**.
- **Used when**:
  - Writing multi-line text in a single string.
  - Structuring output neatly in the console.

```javascript
let message = "The new Apple iPhone\nhas been launched.";
console.log(message);
```

**Output:**
```
The new Apple iPhone
has been launched.
```

---

### `\t` — Tab Space

- Inserts a **horizontal tab**, equivalent to about **four spaces**.
- **Used when**:
  - Aligning values for better readability.

```javascript
let specs = "iPhone 14\thas been launched";
console.log(specs);
```

**Output:**
```
iPhone 14    has been launched
```

---

## Demonstrating Special Characters

In JavaScript, you can include these escape sequences directly within strings:

```javascript
let text = "Hello\nWorld!";
console.log(text);
```

**Output:**
```
Hello
World!
```

```javascript
let text = "Name:\tJohn";
console.log(text);
```

**Output:**
```
Name:    John
```

> 🔎 These special sequences **only work inside strings**, usually enclosed in `" "` or `' '` or backticks `` ` ``, and are interpreted at runtime.

---

## How to Print a Backslash (`\`)

Since the **backslash** is used to start escape sequences, printing an actual backslash requires:

### Double Backslash: `\\`

```javascript
let path = "C:\\Users\\Documents";
console.log(path);
```

**Output:**
```
C:\Users\Documents
```

- This is because the **first backslash escapes the second**, resulting in a single backslash being printed.

## Other Special Characters

Although `\n` and `\t` are the most commonly used, other escape sequences exist:

| Escape Code | Meaning               |
|-------------|------------------------|
| `\n`        | New line               |
| `\t`        | Tab space              |
| `\\`        | Backslash              |
| `\'`        | Single quote (in `' '`)|
| `\"`        | Double quote (in `" "`)|
| `\b`        | Backspace              |
| `\r`        | Carriage return        |

> 💡 While `\n` and `\t` are frequently used, others like `\b`, `\r`, etc., are **less common in daily programming**.

## Practical Example Combining Special Characters

```javascript
let name = "Sanket";
let age = 24;
console.log(name + "\n" + age);
```

**Output:**
```
Sanket
24
```

- Here, the **`\n` adds a line break** between the name and the age.

## Final Summary

This lesson introduced the concept of **special characters (escape sequences)** in JavaScript:

### ✅ Key Learnings:
- Special characters are used within strings to represent non-printing characters (e.g., newline, tab).
- **`\n`** inserts a new line.
- **`\t`** inserts a tab.
- **`\\`** is used to print a literal backslash.
- These characters help format console output, display multi-line strings, and improve code readability.

### 💡 Additional notes:
- Escape characters behave consistently across many programming languages.
- They are especially helpful in **string manipulation**, **output formatting**, and **template rendering**.

Understanding these characters gives you more control over **how your output appears**, which is essential for building clean and readable user interfaces or logs.
