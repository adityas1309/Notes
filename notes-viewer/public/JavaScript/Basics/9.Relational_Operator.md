## Introduction to Relational Operators

Relational operators (also known as **comparison operators**) are used in programming to compare **two values** and return a **Boolean result** — either `true` or `false`.

- They are widely used in conditions, control structures, filtering logic, etc.
- These operators evaluate **relationships** between two operands, such as:
  - Is one greater than the other?
  - Are they equal?
  - Is one less than or equal to the other?

---

## What Are Relational Operators?

Relational operators compare values **numerically or lexically** and return `true` if the comparison is valid, `false` otherwise.

### Key Symbols and Their Meaning

| Operator | Symbol        | Description               | Example          |
|----------|---------------|---------------------------|------------------|
| Less Than | `<`         | Checks if left < right    | `10 < 12` → true |
| Greater Than | `>`      | Checks if left > right    | `5 > 2` → true   |
| Less Than or Equal To | `<=` | Checks if left ≤ right | `10 <= 10` → true |
| Greater Than or Equal To | `>=` | Checks if left ≥ right | `5 >= 7` → false |

### Operands in Comparisons

- **Operands** are the values you compare.
- Example:
  ```javascript
  10 < 12  // 10 and 12 are operands
  ```

---

## Working and Examples

The operator evaluates whether the relation is true or false, and JavaScript returns the corresponding Boolean result.

### Code Demonstration

```javascript
let x = 10;
let y = 20;
let z = 5;
let a = 10;

console.log("Is x < z:", x < z);         // false (10 < 5 → false)
console.log("Is y > z:", y > z);         // true  (20 > 5 → true)
console.log("Is x <= z:", x <= z);       // false (10 <= 5 → false)
console.log("Is x >= a:", x >= a);       // true  (10 >= 10 → true)
```

---

## Output Interpretation

Let's break down what happens when the code runs:

- `x < z` → `10 < 5` → **false**
- `y > z` → `20 > 5` → **true**
- `x <= z` → `10 <= 5` → **false**
- `x >= a` → `10 >= 10` → **true**  
  - Because `>=` checks if the value is either **greater than** OR **equal to**.

> 📌 Note: Depending on your **editor’s font**, `<=` and `>=` might appear differently (e.g., compressed as a single symbol). This is only visual and has no effect on functionality.
