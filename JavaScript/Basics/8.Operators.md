## Introduction to Operators

Operators in JavaScript are symbols or keywords that perform specific operations on values (known as operands).

- Programming languages provide **predefined operators** for common tasks.
- Operations can be:
  - **Mathematical** (e.g., addition, multiplication)
  - **Assignment-based** (e.g., assigning or updating variable values)
- JavaScript includes a rich set of operators, including:
  - **Arithmetic operators**
  - **Assignment operators**
  - (and others such as comparison, logical, etc., which are covered in future lessons)

---

## Arithmetic Operators

Arithmetic operators perform **basic mathematical operations**.

### Basic Arithmetic Operators

| Operator | Symbol | Description           | Example (x=10, y=3) | Result  |
|----------|--------|-----------------------|----------------------|---------|
| Addition | `+`    | Adds two values       | `x + y`              | `13`    |
| Subtract | `-`    | Subtracts right from left | `x - y`          | `7`     |
| Multiply | `*`    | Multiplies two values | `x * y`              | `30`    |
| Divide   | `/`    | Divides left by right | `x / y`              | `3.33`  |
| Modulo   | `%`    | Remainder of division | `x % y`              | `1`     |

### Operands and Operators

- **Operands**: The values on which the operation is performed.
- **Operator**: Symbol that represents the operation.

> Example: In `x + y`  
> `x` and `y` are **operands**, `+` is the **operator**.

### Demonstration of Arithmetic Operators

```javascript
let x = 10;
let y = 3;

console.log(x + y); // 13
console.log(x - y); // 7
console.log(x * y); // 30
console.log(x / y); // 3.333...
console.log(x % y); // 1
```

### Exponentiation Operator

- JavaScript supports **exponentiation** using `**` (double asterisk).
- Syntax: `a ** b` is equivalent to a raised to the power of b.

```javascript
let y = 3;

console.log(y ** 2); // 9
console.log(y ** 3); // 27
```

### Summary: Arithmetic Operators

- Arithmetic operators cover basic math operations.
- Operate on two values (operands).
- JavaScript includes an exponentiation operator (`**`) for powers.

## Assignment Operators

Assignment operators assign values to variables. They can also **combine operations** with assignment.

### Basic Assignment

- `=` is the **basic assignment operator**.
- It assigns the value on the right-hand side (RHS) to the variable on the left-hand side (LHS).

```javascript
let a = 10; // Assigns 10 to a
```

### Compound Assignment Operators

| Operator       | Equivalent to        | Description                         |
|----------------|----------------------|-------------------------------------|
| `+=`           | `a = a + b`          | Adds and assigns                    |
| `-=`           | `a = a - b`          | Subtracts and assigns               |
| `*=`           | `a = a * b`          | Multiplies and assigns              |
| `/=`           | `a = a / b`          | Divides and assigns                 |
| `%=`           | `a = a % b`          | Modulus and assigns (remainder)     |
| `**=`          | `a = a ** b`         | Exponentiation and assigns          |

### Step-by-Step Demo with Compound Assignments

```javascript
let a = 10;        // a = 10
a += 7;            // a = a + 7 → a = 17
a %= 3;            // a = a % 3 → a = 2
a *= 5;            // a = a * 5 → a = 10
a -= 3;            // a = a - 3 → a = 7
a /= 2;            // a = a / 2 → a = 3.5
a **= 2;           // a = a ** 2 → a = 12.25

console.log(a);    // Final output: 12.25
```

Each operation:
- Takes the current value of `a`
- Applies a mathematical operation with the right-hand value
- **Reassigns** the result to `a`

### Summary: Assignment Operators

- The `=` operator assigns values.
- Compound assignment operators simplify expressions by combining operation and reassignment.
- These are useful for updating variables dynamically, especially in loops and iterative logic.

## Final Overall Summary

In this lesson, you learned about two important categories of JavaScript operators:

### 🔢 Arithmetic Operators
- Used for performing basic math: `+`, `-`, `*`, `/`, `%`, `**`
- Work on **two operands** to calculate results like sum, difference, quotient, remainder, and powers.

### 📥 Assignment Operators
- The basic `=` assigns a value.
- Compound operators like `+=`, `-=`, `*=`, `/=`, `%=`, and `**=` simplify common update patterns by combining operation with assignment.

### Key Takeaways:
- Operators are fundamental tools that allow programs to **compute values** and **manage state**.
- Using compound assignment operators leads to **cleaner, more concise code**.
- JavaScript offers a rich set of operators to perform most common tasks efficiently.

Understanding these operators equips you with the ability to perform calculations, update variables dynamically, and write logical instructions in JavaScript.
